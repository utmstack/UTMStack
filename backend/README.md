# UTMStack Backend (Go)

Go rewrite of the legacy `backend-legacy/` (Java/Spring) service. Clean
architecture, one module per domain.

## Layout

```
backend/
├── main.go              # entry + top-level Swagger annotations
├── server.go            # HTTP engine, middleware, route registration
├── config.go            # env-driven config
├── init.go              # logger + DB connection + migrations
├── modules.go           # DI hub
├── server_test.go
├── database/migrations.go
├── migrations/          # *.up.sql / *.down.sql for SQL migrations
├── docs/                # generated by `swag init` — do not edit
├── pkg/                 # cross-module utilities
│   ├── env/             # env var helpers
│   ├── logger/          # slog + Gin middleware
│   └── http/middleware/ # auth + permission middleware
└── modules/<name>/      # one folder per domain module
    ├── domain/          # GORM entities
    ├── dto/             # request/response shapes
    ├── connectors/      # interfaces (Repository, Usecase)
    ├── repository/      # concrete pg* implementations
    ├── usecase/         # business logic
    ├── handler/         # Gin HTTP handlers + Swagger annotations
    ├── module.go        # DI struct
    └── routes.go        # RegisterRoutes(group, module, middlewares...)
```

`modules/health/` is the canonical example — copy it to start a new module.

## Run

```sh
go mod tidy
go run .
```

Required env vars (defaults shown):

| Var | Default | Notes |
|---|---|---|
| `APP_PORT` | `8080` | |
| `DEV_MODE` | `false` | enables CORS for `localhost` origins |
| `JWT_ISSUER` | `""` | URL of IAM service for JWKS |
| `DB_HOST` | `localhost` | |
| `DB_PORT` | `5432` | |
| `DB_NAME` | `utmstack` | |
| `DB_USER` | `postgres` | |
| `DB_PASSWORD` | `""` | |

## Swagger

Annotations live on each handler (see `modules/health/handler/health.go`) and on
`main()` in `main.go`. Generate the spec:

```sh
go install github.com/swaggo/swag/cmd/swag@latest
swag init --parseDependency --parseInternal
```

Output goes to `docs/`. The blank `_ "…/backend/docs"` import in `main.go` wires
the generated spec into the runtime; the handler is mounted at `/swagger/*any`
in `server.go`.

## Adding a module

1. `cp -r modules/health modules/<name>` and rename the package.
2. Replace the example handler/usecase/repository with your domain.
3. In `modules.go`, build repos → usecases → `NewModule(...)`, store on the `modules` struct.
4. In `server.go` `registerRoutes`, add `<name>.RegisterRoutes(api.Group("/<name>"), m.<name>, userAuth)`.
5. In `database/migrations.go` `Models()`, append your domain types so AutoMigrate picks them up.
