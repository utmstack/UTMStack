# UTMStack 11.0.4

This is the release notes for **UTMStack v11.0.3**, a minor update focused on bug fixes and performance improvements.

## Fixed Issues



## Features

- Introduced a new Adversary View within the Threat Management module, enabling visualization of the relationships between adversaries, their generated alerts, and associated echoes. This enhancement provides analysts with a clearer understanding of attacker behavior, campaign patterns, and alert propagation over time.
- Added SQL-based querying support to the LogExplorer module, enabling users to write and execute SQL queries over OpenSearch indices for more flexible log analysis.
