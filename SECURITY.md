# Security Policy

## Supported Versions

| Version  | Status | EoS/EoL      |
|----------|--------|--------------|
| 9.x      | ❌     | Jan 15, 2024 |
| 10.x     | 🕐     | Dec 5, 2026  |
| 11.x     | ✅     | Dec 5, 2027  |
| 12.x LTS | 📅     | Nov 15, 2032 |

### Legend
```list
✅ Current version, receives new features, security and bug fixes
🕐 Extended support, receives security and high severity bug fixes only
📅 In development, not yet generally available
❌ Unsupported
```

Please report security vulnerabilities to support@utmstack.com
